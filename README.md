# VIA LINK Disaster Resource Map

## Project Overview

The VIA LINK Disaster Resource Map is a web application that provides the public with an easy way to locate disaster-related resources during emergency events.

Resources are maintained through a Google Sheet so that VIA LINK staff can add, edit, or remove information without modifying the application's code.

---

## Project Goals

- Display disaster resources on an interactive Google Map.
- Read resource information from a Google Sheet.
- Support filtering by resource category.
- Provide search by address or ZIP code.
- Be mobile-friendly.
- Be reusable for future disaster events.

---

## Development Philosophy

This project is being built with the following principles:

- Keep the code simple and readable.
- One file should have one responsibility.
- Document major design decisions.
- Build reusable components.
- Maintain clear separation between presentation, logic, and configuration.
